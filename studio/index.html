                收不到没 @ 它的群消息？
                
    
                  
    这是 QQ 平台设置，不在插件里，也不在开放平台后台：
    
                  
      
                    
    1. 让群主在手机 QQ 打开这个群 → 右上角「群设置」
      2. 
                    
    2. 找到「群机器人 / 机器人管理」→ 选中这个机器人
      3. 
                    
    3. 把「机器人可获取的群聊消息范围」改成「获取群内全部消息」
      4. 
                  
    
                  
    只有群主能改，而且每个群都要单独设置。设好后日志里会出现 群消息模式：全量（GROUP_MESSAGE_CREATE）。
